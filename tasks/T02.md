# T02 Gradle scaffold and plugin skeleton
size: M | who: sonnet-builder | hard: no | deps: M01

## Goal
An empty but working plugin called `forzammilmod` that builds into a jar, loads on Spigot 1.21.4 and answers `/forzammilmod version`.

## Steps
1. Gradle wrapper (current stable), Kotlin DSL, Java 21 toolchain. `settings.gradle.kts` with `rootProject.name = "forzammilmod"`.
2. Repositories: Maven Central and `https://hub.spigotmc.org/nexus/content/repositories/snapshots/` (add `https://oss.sonatype.org/content/repositories/snapshots/` only if resolution fails). `compileOnly("org.spigotmc:spigot-api:1.21.4-R0.1-SNAPSHOT")`. JUnit 5 for tests.
3. Version comes from `gradle.properties` (`version=0.1.0`) and is expanded into `plugin.yml` with `processResources`.
4. `plugin.yml`: `name: forzammilmod`, `main: dev.egorgrigorciuc.forzammilmod.ForzammilMod`, `api-version: '1.21'`, `softdepend: [BetterModel, SkinsRestorer]`, commands `forzammilmod` and `emote` (emote can be a stub that says "coming soon" for now).
5. Classes: `ForzammilMod` (main), `Access` with `public static final String OWNER_NAME = "Forzammil"` and `isOwner(Player)`, `ForzammilCommand` with subcommand routing and tab completion. `/forzammilmod version` prints the plugin version.
6. Jar name `forzammilmod-<version>.jar`.
7. `.gitignore`: `build/`, `.gradle/`, `server/`, `*.log`, `.env`, `.claude/settings.local.json`, `.claude/dashboard/events.jsonl`, `.claude/dashboard/server.pid`.
8. One trivial unit test (e.g. `Access.isOwnerName("Forzammil")` true, `"forzammil"` false) so the test pipeline exists.

## Done when
`./gradlew build` passes and produces `build/libs/forzammilmod-0.1.0.jar`.

## Out of scope
Language files (T05), server setup (T06).
