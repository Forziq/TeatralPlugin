# T26 Vehicle spawn pads (command block and button)
size: M | who: sonnet-builder | hard: no | deps: G2

## Goal
Egor builds a pad from a command block with a button on it. Anyone who presses the button gets that pad's vehicle (tank, jeep, or anything added later) 2 blocks above the command block. Typing `/fmod vehicle spawn` in chat stays owner-only.

## Steps
1. Let `/fmod vehicle spawn <type>` run from a command block (`BlockCommandSender`). Spawn point: centre of the command block's x/z, 2 blocks above the command block. Face the vehicle the way the command block points; if it points up or down, face south.
2. Access: add `Access.canSpawnVehicle(CommandSender)` that allows the owner, the console and command blocks. Remove and update stay `isOwner`. Only ops can place or edit command blocks, so this doesn't let friends spawn by typing.
3. Keep pads tidy, all values hard-coded:
   - If a vehicle is already within 3 blocks of the spawn point, don't spawn another. Tell players within 6 blocks "There's already a vehicle on the pad".
   - At most 10 vehicles on the server at once. Above that, tell nearby players to free one up.
   - A vehicle with no driver for 10 minutes despawns. Log it.
4. Pure classes for "can this pad spawn" (occupied, cap) and the idle timer, with unit tests.
5. Vehicle types still come from `VehicleType`, so every vehicle added later works on a pad without extra code. Tab completion unchanged.
6. New messages in `lang/en.yml` and `lang/ru.yml`, natural Russian.

## Checks
