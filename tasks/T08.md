# T08 Updater, pack sender and owner check
size: L | who: sonnet-builder | hard: no | deps: T05, T07

## Goal
The plugin keeps itself up to date from the private GitHub repo and makes every player load the right resource pack.

## Steps
1. `config.yml` (copied to the data folder on first run) with exactly one value: `github-token: ""` plus a comment in English explaining what it's for. Repo owner/name are constants.
2. `UpdateService`:
   - On enable, async: if the token is set, call `GET https://api.github.com/repos/{owner}/TeatralPlugin/releases/latest` (`Authorization: Bearer`, `Accept: application/vnd.github+json`, `X-GitHub-Api-Version: 2022-11-28`). Compare `tag_name` with the running version (semantic compare, unit tested).
   - If newer: download the `.jar` asset via `GET /repos/{owner}/TeatralPlugin/releases/assets/{id}` with `Accept: application/octet-stream`. Follow the redirect yourself and drop the Authorization header on the redirected request. Save to `Bukkit.getUpdateFolderFile()` as the same file name as the running jar so Spigot swaps it on restart. Log one clear line.
   - `/forzammilmod update` (owner only) runs the same check now and replies in the player's language: already up to date / downloaded vX, restart the server from exaroton / no token set / error.
   - Never block the main thread, never crash on network errors, 15 s timeouts.
3. `PackService`: read `pack.properties` from the jar. On join (1 tick later), `player.setResourcePack(UUID, url, sha1Bytes, prompt, true)` with a translated prompt. On `PlayerResourcePackStatusEvent` `DECLINED` or `FAILED_DOWNLOAD`, kick with a translated message saying the pack is required. If pack.properties is missing (dev build), log a warning and skip.
4. Owner check: vehicles and `update` use `Access.isOwner(player)` (exact name `Forzammil`). Everyone else gets the translated "no permission" message.
5. Messages in en.yml and ru.yml.
6. Tests: version compare, redirect handling (mock `HttpClient` or a tiny local `HttpServer` in the test), pack.properties parsing.
