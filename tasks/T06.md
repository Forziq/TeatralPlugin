# T06 Local test server and smoke test script
size: M | who: sonnet-builder | hard: no | deps: T02

## Goal
A local Spigot 1.21.4 server in `server/` (gitignored) with BetterModel and SkinsRestorer, and a script that proves the plugin loads cleanly.

## Steps
1. `scripts/setup-server.sh`: download BuildTools from `https://hub.spigotmc.org/jenkins/job/BuildTools/lastSuccessfulBuild/artifact/target/BuildTools.jar` into `server/buildtools/`, run `java -jar BuildTools.jar --rev 1.21.4` with Java 21, copy the result to `server/spigot-1.21.4.jar`. Skip if it already exists.
2. Write `server/eula.txt` (`eula=true`) and `server/server.properties` with `online-mode=false`, `level-type=minecraft:flat`, `spawn-protection=0`, `max-players=5`, `motd=forzammilmod test`.
3. Download plugins from the Modrinth API (`https://api.modrinth.com/v2/project/<slug>/version?loaders=["spigot"]&game_versions=["1.21.4"]`): BetterModel (slug `bettermodel`, use 3.3.0 or the newest release that lists 1.21.4) and SkinsRestorer (slug `skinsrestorer`). Pin the exact versions and file names in `docs/versions.md`.
4. `scripts/server-start.sh`: copy the freshly built plugin jar into `server/plugins/`, start the server in the foreground for Egor to join on `localhost` (`-Xms1G -Xmx3G`).
5. `scripts/smoke-test.sh`: build, copy the jar, start the server headless with stdin on a named pipe, wait up to 120 s for `Done (` in `server/logs/latest.log`, then check:
   - `[forzammilmod] Enabling forzammilmod` appears
   - BetterModel and SkinsRestorer enabled
   - no lines containing `Error occurred while enabling`, `Could not load`, or a stack trace mentioning `dev.egorgrigorciuc`
   Send `stop`, wait for exit, print only a short PASS/FAIL summary plus the matching error lines (max 40). Exit code 0 or 1.
6. Delete the world folders between smoke runs only when `--fresh` is passed.

## Done when
`scripts/smoke-test.sh` prints PASS on the Mac.
