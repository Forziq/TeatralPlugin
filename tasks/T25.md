# T25 Rename the commands to /fmod
size: M | who: sonnet-builder | hard: no | deps: T13

## Goal
Every plugin command starts with `/fmod` instead of `/forzammilmod`. Only the commands change: the plugin name, jar name, data folder (`plugins/forzammilmod/`), package, sound keys (`forzammilmod:...`), repo and release names all stay as they are. `/emote` stays as it is.

## Steps
1. `plugin.yml`: rename the command `forzammilmod` to `fmod`. Don't keep `forzammilmod` as an alias.
2. Update the command class, tab completion, help and usage text, and every message in `lang/en.yml` and `lang/ru.yml` that shows a command (e.g. "type /fmod update", "/fmod music play stalnoy_marsh").
3. Update tests that mention the old command.
4. Replace `/forzammilmod` with `/fmod` in manual.md, docs/notes/*.md, assets/*/README.md and the task files that aren't done yet. Leave finished task files and old log lines alone.
5. Publish v0.2.1 with `scripts/release.sh 0.2.1`.
6. Add to the top of manual.md G1 "Get ready": on the exaroton server type `/forzammilmod update` one last time (the server is still on the old version), restart, and from then on everything is `/fmod`.

## Done when
`grep -rn "/forzammilmod" src/ assets/ manual.md` finds nothing, tests and smoke test pass, and v0.2.1 is released.
