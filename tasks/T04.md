## Steps
1. Find the ElevenLabs sound-effect tool and read its schema (duration, loop and prompt-strength options). Use loop mode for the loop sounds if the tool has it.
2. Generate each sound with two takes. Save the original files to `assets/sounds/raw/` (gitignored).
3. Convert: `ffmpeg -y -i in -ac 1 -ar 44100 -c:a libvorbis -q:a 5 out.ogg`. Take 1 goes to `assets/sounds/<name>.ogg`, take 2 to `assets/sounds/alt/<name>.ogg`. Trim leading silence with `silenceremove` for one-shots.
4. Write `assets/pack/assets/forzammilmod/sounds.json` mapping `forzammilmod:<name>` to `forzammilmod:<name>` (one-shots `"stream": false`; loops too, they're short).
5. Write `assets/sounds/README.md`: a table of name, prompt used, length, and a line on how to swap a take.
6. Report credits used and remaining if the tool shows them. If credits run low, stop after the vehicle sounds and note what's missing.
