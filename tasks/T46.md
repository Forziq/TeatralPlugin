# T46 Version checks between plugin and pack
size: M | who: sonnet-builder | hard: no | deps: T45

Phase 6 starts here: polish.

## Goal
If the server's plugin, the published pack or BetterModel don't match, Egor finds out straight away instead of seeing broken models.

## Steps
1. The pack build writes the plugin version into the pack (`pack.mcmeta` description and a small `forzammilmod/version.txt`). The plugin already knows the pack URL and SHA-1 from `pack.properties`; on startup, log clearly if they don't belong to this plugin version.
2. On startup, check the BetterModel version against `docs/versions.md` (copy the pinned version into the jar at build). Log a loud warning if it differs, and tell Egor in game when he joins.
3. `/fmod version` shows plugin, pack and BetterModel versions, each marked OK or mismatched.
4. Unit tests for the comparison logic.
