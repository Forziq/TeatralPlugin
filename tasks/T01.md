# T01 Install tools, create the GitHub repo, add Context7
size: S | who: haiku-scout | hard: no | deps: none

## Goal
The Mac has everything later tasks need, the folder is a git repo with a private GitHub remote, and Context7 is registered as an MCP server.

## Steps
1. Check and report versions: `java -version`, `/usr/libexec/java_home -V`, `node -v`, `git --version`, `gh --version`, `ffmpeg -version | head -1`, `op --version`, `brew --version`.
2. Install whatever is missing with Homebrew: `openjdk@21`, `node`, `gh`, `ffmpeg`, `1password-cli`. If `openjdk@21` needs the `sudo ln -sfn ...` symlink step, don't run sudo; add it to manual.md under M00 and use `JAVA_HOME=$(brew --prefix openjdk@21)/libexec/openjdk.jdk/Contents/Home` in scripts instead.
3. The folder is already a git repo with `origin` set to `https://github.com/Forziq/TeatralPlugin.git` (no commits yet). Check `.claude/` exists (Egor runs `scripts/install-harness.sh` first; if `claude-setup/` is still there, stop and point him to manual.md M00). Commit everything as `T01: harness and plan`.
4. `gh auth status`. If not logged in, try `gh auth login --web --git-protocol https` in the background and finish the device-code page with Claude in Chrome (Egor's 1Password fills the GitHub login). If that fails, stop and point Egor to manual.md M00.
5. `gh repo view Forziq/TeatralPlugin --json visibility`. If it exists, make sure it's private (`gh repo edit Forziq/TeatralPlugin --visibility private --accept-visibility-change-consequences` if not) and `git push -u origin main`. If it doesn't exist, `gh repo create Forziq/TeatralPlugin --private --source . --push`. The repo owner is `Forziq`, so the Pages URL will be `https://forziq.github.io/TeatralPlugin/`.
6. Register Context7 for this project: `claude mcp add --scope project context7 -- npx -y @upstash/context7-mcp`. This writes `.mcp.json`; commit it.
7. Run `claude mcp list` and note whether an ElevenLabs server is visible to Claude Code. Write the result in progress.md notes (T04 needs it).

## Done when
- All tools installed (or listed in manual.md), repo pushed, `.mcp.json` committed.
- progress.md log says which tools were installed and whether ElevenLabs is visible.

## Out of scope
Any Gradle or Java code.
