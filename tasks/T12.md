# T12 Emote commands and cancel rules
size: L | who: sonnet-builder | hard: no | deps: T11, T05

## Goal
Any player can `/emote wave` and `/emote stop`. The emote stops on its own when the player moves, takes damage, or leaves.

## Steps
1. `EmoteService` with `play(player, "wave")` and `stop(player, reason)`, one active emote per player, using the API from docs/notes/bettermodel.md.
2. `/emote wave` plays it; `/emote stop` stops it; `/emote` alone lists emotes. Tab completion. Translated messages (started, stopped, unknown emote, already playing).
3. Cancel rules: `PlayerMoveEvent` only when the block position or x/z changes by more than 0.05 (looking around is fine); `EntityDamageEvent` on the player; `PlayerQuitEvent`; `PlayerDeathEvent`; teleport. Also stop automatically when the animation ends.
4. Pure-logic class for "did this move count as moving" so it can be unit tested.
5. No cooldowns, GUI, sounds or config (that's Phase 3).
