# T07 Resource pack build and release pipeline (Pages)
size: M | who: sonnet-builder | hard: no | deps: T06

## Goal
One command, `scripts/release.sh <version>`, that builds the jar and the resource pack, publishes the pack to GitHub Pages and creates a GitHub Release.

## Research first (ask haiku-scout)
- Where BetterModel writes its generated pack (folder or zip, path) and the config options to stop BetterModel sending its own pack to players or editing server.properties. Our plugin sends the pack instead.
- Pack format number for 1.21.4 (expected 46).
Save the answers to `docs/notes/bettermodel-pack.md`.

## Steps
1. `scripts/build-pack.sh`: run the smoke test (so BetterModel generates its pack from our models), take BetterModel's output, merge in `assets/pack/` (our `pack.mcmeta`, `sounds.json`, lang files) and `assets/sounds/*.ogg` into `assets/minecraft`-style layout under `assets/forzammilmod/sounds/`. Zip to `build/pack/forzammilmod-pack-<version>.zip`, print its SHA-1.
2. `scripts/release.sh <version>`:
   - set `version` in gradle.properties
   - build the pack, write `src/main/resources/pack.properties` (`url=https://<owner>.github.io/TeatralPlugin/pack/forzammilmod-pack-<version>.zip`, `sha1=<hex>`), then build the jar (so the jar knows its own pack)
   - publish the zip to the `gh-pages` branch under `pack/` (keep old zips; Pages caches, so file names are versioned)
   - write `release.json` (`version`, `jar`, `packUrl`, `packSha1`) and run `gh release create v<version> build/libs/forzammilmod-<version>.jar release.json --notes-file <generated>`
   - commit and tag
3. Enable Pages on the private repo from the `gh-pages` branch: `gh api -X POST repos/{owner}/TeatralPlugin/pages -f "source[branch]=gh-pages" -f "source[path]=/"` (skip if already enabled). Pages on a private repo needs Egor's paid GitHub plan, which he has.
4. Verify the pack URL answers `200` with `curl -sI` after publishing (Pages can take a minute or two; retry for up to 3 minutes).
5. `--dry-run` flag: does everything except pushing and creating the release.

## Done when
`scripts/release.sh 0.0.1 --dry-run` produces a jar and a zip, and the zip contains `pack.mcmeta`, BetterModel's assets and our sounds.
