# T05 Language system (English, Russian, plurals)
size: M | who: sonnet-builder | hard: no | deps: T02

## Goal
Every player-facing message comes from `lang/en.yml` or `lang/ru.yml`, picked by the player's client language, with correct Russian plurals.

## Steps
1. `Lang` service loads both files from the jar at startup (`YamlConfiguration.loadConfiguration(new InputStreamReader(..., UTF_8))`). Files are never copied to the data folder: they aren't config.
2. Language choice: `player.getLocale()` starting with `ru` gets Russian, anything else English. Console gets English. Re-check on `PlayerLocaleChangeEvent` (cache per UUID, clear on quit).
3. API: `Lang.msg(CommandSender, "key", Map/varargs placeholders)` and `Lang.plural(CommandSender, "key", n)`. Placeholders `{name}`. Colour codes with `&`. Missing key in ru falls back to en, missing in both returns the key in red and logs a warning once.
4. Plurals: en uses `one`/`other`. ru uses `one` (n%10==1 and n%100!=11), `few` (n%10 in 2..4 and n%100 not in 12..14), `many` (everything else). Keys look like `reload.seconds.one`, `.few`, `.many`, `.other`.
5. Move the existing messages from T02 (version, unknown subcommand, no permission, emote stub) into the files.
6. Russian must read like a native speaker wrote it for gamers: short, natural, informal "ты" form, Minecraft community terms (e.g. "ресурспак"), no word-for-word translation. Use «ёлочки» quotes if quotes are needed.
7. Unit tests: plural rule for 0, 1, 2, 4, 5, 11, 12, 14, 21, 22, 25, 101, 111; fallback to English; placeholder replacement.

## Done when
`./gradlew test` passes, and a test checks that en.yml and ru.yml have exactly the same keys.

## Notes
Every later task that adds a message adds it to both files. Main reviews new Russian text on L tasks.
