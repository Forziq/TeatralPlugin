size: S | who: haiku-scout | hard: no | deps: T08

## Goal
v0.1.0 is on GitHub, its pack is on Pages, and Egor has a jar to upload and a token to paste.

## Steps
1. `scripts/release.sh 0.1.0`. Confirm the release exists (`gh release view v0.1.0`) and the pack URL returns 200.
2. Copy the jar to `dist/forzammilmod-0.1.0.jar` (gitignored) so Egor can find it in Finder.
3. Create a fine-grained GitHub token for the server using Claude in Chrome at github.com/settings/personal-access-tokens/new: name `forzammilmod-server`, resource owner Egor, repository access "Only select repositories: TeatralPlugin", permissions Contents: Read-only (Metadata: Read-only is automatic), expiry 1 year. Save it in 1Password as `forzammilmod GitHub token` (via the 1Password extension or `op item create` if the CLI is signed in). Never write it to a file in the repo or print it in the chat. If any of this fails, add the steps to manual.md M02 and carry on.
4. Update manual.md M02 with the exact jar path and the plugin file names/versions from docs/versions.md.
