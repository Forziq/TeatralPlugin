# T22 WWII-style music with ElevenLabs
size: M | who: sonnet-builder | hard: no | deps: T04

Comes straight after T11 because Egor's ElevenLabs plan runs out soon.

## Goal
Five instrumental tracks and one comic song with Russian lyrics, saved as stereo `.ogg` in `assets/music/`, each with an id, an English name and a Russian name.

## Tracks
Every track has a Russian name. Ids (what players type) and the name English-language players see are that Russian name written in Latin letters; Russian players see it in Cyrillic. Ids are lowercase with underscores. Never name or imitate a real song, composer or band in a prompt (no Katyusha, Svyashchennaya Voyna, Erika and so on); describe the style instead.

## The comic song
1. Write the lyrics first in `assets/music/lyrics/okopnye_chastushki.txt`: 6 to 8 chastushki (four-line rhyming verses, the traditional form for rude funny ditties), with a short accordion break marked between some verses.
2. Egor asked for very silly, rude jokes with words like пиписьки, дрочили, сосали and similar. Use them for daft wordplay and double meanings about army life: a tank that won't start, the sergeant, porridge from the field kitchen, foot wraps, the latrine, letters from home, the cook. Proper rhyme and rhythm so it actually sounds like chastushki.
3. Hard limits: no slurs about any nationality or group, no jokes about real war crimes, victims or the Holocaust, no real people or politicians, no Nazi symbols or praise, nothing involving children.
4. Before spending credits on it, show Egor the lyrics (AskUserQuestion: Generate as is / I'll edit the file first / Skip the song). Only generate once he says go.
5. If ElevenLabs refuses or cleans up the explicit words, try once with the Runway music tool if Claude Code can see it. If that also refuses, keep the instrumental version (`okopnye_chastushki` without vocals) and say so in the log.

## Steps
1. Check the credits left. Music costs more than sound effects, so do one take per track. Regenerate a track once only if it's clearly broken (silence, wrong style, vocals in an instrumental).
2. Find the ElevenLabs music model through the creative flow tools (`creative_get_flow_node_types`, then read its model guide for length limits, lyrics input and any explicit-content setting). Reuse the flow from T04 if it still exists.
3. Generate the instrumentals first, in table order, then the song once Egor has approved the lyrics.
4. Save originals to `assets/music/raw/` (gitignored). Convert to stereo Ogg Vorbis at 44.1 kHz with the same route T04 used (ffmpeg to wav, then `oggenc -q 4`). Stereo matters: Minecraft plays stereo sounds without direction or fade, which is what music needs. Normalise loudness so tracks are roughly equally loud (`ffmpeg -af loudnorm=I=-16`). Trim silence at both ends.
5. Write `assets/music/tracks.yml`: for each track the id, `en` and `ru` names, length in milliseconds (from `ffprobe`), and whether it has vocals.
6. Add the tracks to `assets/pack/assets/forzammilmod/sounds.json` as `forzammilmod:music.<id>` with `"stream": true`, and make `scripts/build-pack.sh` copy `assets/music/*.ogg` into `assets/forzammilmod/sounds/music/`.
7. Write `assets/music/README.md`: a table of id, names, length, prompt used, credits spent.

## Done when
At least the five instrumentals exist as stereo ogg with lengths in tracks.yml, sounds.json is valid, a dry-run pack build includes them, and everything is committed. Report the pack size before and after.
