# T50 Our own greeting emote, with a configurable name and sound
size: M | who: sonnet-builder | hard: no | deps: T26

Phase 3 is just this emote: Egor dropped the other planned emotes and the emote menu. The MVP "no config" rule is relaxed for this emote only.

## Goal
The group's own way to say hi, as an emote. Egor can change its name and its sound in `config.yml` on the server without a new release.

## The gesture
Stand up straight, legs together, and raise the right hand up 45 degrees and a bit to the left.
- Body and head straight and still, legs together (both leg bones at 0, no stance).
- Right arm: straight, raised to 45 degrees above horizontal in front of the body, angled about 15 degrees to the left (across towards the body's centre line). Palm faces forward if the rig shows it.
- Timing (2.5 s, play once): raise over 0.4 s with a slight overshoot, hold still for 1.6 s, lower over 0.5 s. Ease in and out on every keyframe so it doesn't look robotic.
- Keep the angles in one place in the animation so Egor can tweak them in Blockbench if it doesn't match the real thing.

## Config
Add to `config.yml` (read on startup and by `/fmod reload`, below):
```yaml
greeting:
  id: greeting            # what players type: /emote greeting
  name: "Greeting"        # shown in English
  name-ru: "Приветствие"  # shown in Russian; falls back to name if blank
  sound: "forzammilmod:emote.whoosh"  # any sound key, vanilla or ours; blank = silent
  volume: 1.0
  pitch: 1.0
```
- `id` must be lowercase letters, digits or underscores and must not be `wave` or `stop`. If it's invalid, log a warning and use `greeting`.
- `sound` takes any sound key, so vanilla sounds work too (e.g. `minecraft:entity.player.levelup`). An unknown key just plays nothing, since Minecraft doesn't report it, so log the key once on startup so Egor can spot typos.
- To use a brand-new sound file: drop the `.ogg` (mono) into `assets/sounds/`, release, then put `forzammilmod:<name>` in the config. Add this to manual.md.

## Steps
1. Read docs/notes/bettermodel.md and how `wave` is built in `models/players/forzammil_player.bbmodel`. Add a `greeting` animation the same way (the animation name stays `greeting` whatever the config id is).
2. Make `/emote <configured id>` play it, alongside the existing `wave`, with tab completion and the usual cancel rules (move, damage, quit, death, teleport, end).
3. The sound plays as the greeting starts, heard by everyone within 16 blocks, at the configured volume and pitch.
4. 3-second cooldown per player between emotes, hard-coded, with a translated message using the plural seconds form.
5. `/fmod reload` (owner only): re-reads `config.yml` and updates the greeting's id, names and sound without a restart. Translated reply in both lang files.
6. Unit tests: config parsing with valid, invalid and missing values; the id check; the cooldown; the model JSON has a `greeting` animation of 2.5 s that only moves known bones.
