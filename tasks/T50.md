# T50 Our own greeting emote, with a configurable name and sound
size: M | who: sonnet-builder | hard: no | deps: T30

## Goal
The group's own way to say hi, as an emote. Egor can change its name and its sound in `config.yml` on the server without a new release.

## The gesture
Stand up straight, legs together, and raise the right hand up 45 degrees and a bit to the left.
- Body and head straight and still, legs together (both leg bones at 0, no stance).
- Right arm: straight, raised to 45 degrees above horizontal in front of the body, angled about 15 degrees to the left (across towards the body's centre line). Palm faces forward if the rig shows it.
- Timing (2.5 s, play once): raise over 0.4 s with a slight overshoot, hold still for 1.6 s, lower over 0.5 s. Ease in and out like T29.
- If any of that reads differently in game, Egor tweaks the angles in Blockbench or asks for a quick fix; keep the numbers in one place in the animation so they're easy to find.

## Config
Add to `config.yml` (read on startup and by `/fmod reload`, below):
```yaml
greeting:
  id: greeting            # what players type: /emote greeting
  name: "Greeting"        # shown in English
  name-ru: "Приветствие"  # shown in Russian; falls back to name if blank
  sound: "forzammilmod:emote.whoosh"  # any sound key, vanilla or ours; blank = silent
  volume: 1.0
  pitch: 1.0
```
- `id` must be lowercase letters, digits or underscores and must not clash with another emote. If it's invalid, log a warning and use `greeting`.
- `sound` takes any sound key, so vanilla sounds work too (e.g. `minecraft:entity.player.levelup`). An unknown key just plays nothing; Minecraft doesn't report it, so log the key once on startup so Egor can spot typos.
- To use a brand-new sound file: drop the `.ogg` (mono) into `assets/sounds/`, release, then put `forzammilmod:<name>` in the config. Add this to manual.md.

## Steps
1. Add the `greeting` animation to `models/players/forzammil_player.bbmodel` (animation name stays `greeting` whatever the config id is).
2. Add it to the emote list (T27) as the one entry whose id, names and sound come from config instead of the lang files. It plays once, uses the normal cooldown and cancel rules, and shows in the T31 menu with a distinct icon (e.g. a golden carrot). The sound plays as it starts, heard within 16 blocks.
3. `/fmod reload` (owner only): re-reads `config.yml` and updates the greeting's id, names and sound without a restart. Translated reply in both lang files.
4. Update CLAUDE.md "Fixed decisions": config now holds the GitHub token and the greeting emote settings.
5. Unit tests: config parsing with valid, invalid and missing values; the id clash check; the animation exists with the right length.
