# T11 Model installer and the wave animation
size: L | who: opus-deep | hard: yes | deps: T10

Hard because the .bbmodel has to match BetterModel's player rig exactly and nobody can look at it until Egor joins.

## Goal
On startup the plugin installs its models into BetterModel and the player model has a 2-second `wave` animation where only the right arm moves.

## Steps
1. Read `docs/notes/bettermodel.md`.
2. Add the BetterModel API as `compileOnly`.
3. `ModelInstaller`: on enable, copy every file under `src/main/resources/models/` (players/ and regular models kept in their folders) into BetterModel's model folder if missing or different (compare SHA-1), then trigger a BetterModel reload once if anything changed. Log what changed.
4. Player model `models/players/forzammil_player.bbmodel`, based on BetterModel's example player model (respect its licence; note it in README). Add an animation `wave`, 2.0 s, play once: right arm raises to about 150 degrees over 0.4 s, waves side to side three times, lowers by 2.0 s. Smooth interpolation. Everything else still.
5. Validate the JSON (parse it in a unit test) and that the bone names match what the notes say BetterModel expects.
6. Smoke test: BetterModel logs that it loaded our model with no errors (add a log grep to the summary).

## Checks
L, plus main checks the bone names against the notes. Add a line to manual.md M03 asking Egor to open the file in Blockbench and play the animation once.
