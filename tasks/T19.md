# T19 Jeep on the same driving code
size: M | who: sonnet-builder | hard: no | deps: T16

## Goal
A jeep that uses the driving core with its own stats: about 2.5 times the tank's top speed, quicker acceleration, can't turn on the spot (turn rate scales with speed), no gun.

## Steps
1. `VehicleType.JEEP` stats; turning needs forward or backward speed.
2. Wheels spin with speed if the model's wheel bones allow it (cheap visual, skip if it causes problems).
3. Unit tests for the speed-dependent turning.
