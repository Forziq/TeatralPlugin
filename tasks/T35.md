# T35 Proper tank and jeep models, with track animation
size: L | who: opus-deep | hard: yes | deps: T34

Hard because it replaces the placeholder models without breaking any bone names the code relies on, and nobody sees the result until Egor joins.

## Goal
The tank looks like a WWII medium tank (T-34 style) and the jeep like a 1940s military jeep, both textured, and the tank's tracks look like they move.

## Steps
1. List every bone name the code uses (turret, barrel, muzzle, wheels, seats, hitbox) before touching the models. Keep them all.
2. Rebuild `tank.bbmodel` and `jeep.bbmodel` with more detail (sloped hull, road wheels, track sides, hatch; jeep bonnet, windscreen, spare wheel) and a hand-painted-style texture in each file. Dark olive green, worn edges, a red star on the tank turret. Keep the overall size close to today's so the hitbox values in `VehicleType` still fit; adjust them if not.
3. Track animation: road wheels spin with speed like the jeep's wheels (reuse `WheelSpin`), and the track texture scrolls if BetterModel 2.2.0 supports animated textures (haiku-scout checks); if not, wheels only.
4. Rebuild the pack and check the pack size stays under 30 MB.
5. Update the model JSON test so it checks the required bone names still exist.
