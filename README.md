# forzammilmod

Private Spigot 1.21.4 plugin for a friends' server: emotes first, WWII-style vehicles later. Project rules and workflow are in `CLAUDE.md`.

## Third-party material

`src/main/resources/models/players/forzammil_player.bbmodel` is based on `steve.bbmodel` from [BetterModel](https://github.com/toxicity188/BetterModel) (tag 2.2.0). Its bones, cubes and texture are kept; its animation was replaced with our own `wave`. BetterModel is released under the MIT licence:
